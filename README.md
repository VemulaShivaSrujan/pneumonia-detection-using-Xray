# pneumonia-detection-using-Xray
This project focuses on building a deep learning-based system to detect pneumonia from chest X-ray images. Using convolutional neural networks (CNNs), the model learns to distinguish between healthy lungs and those affected by pneumonia. The goal is to provide a fast, reliable, and accessible diagnostic aid—especially valuable in regions with limited access to radiologists or diagnostic equipment. The project uses publicly available medical imaging datasets and modern deep learning techniques such as transfer learning to achieve high classification performance.

#dataset https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia
